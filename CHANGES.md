# Aurelis Dental — review changes

## Bugs fixed
- **Booking dialog & mobile menu sat under the navbar/grain**: `z-overlay` was never generated by Tailwind v4 (`--z-*` isn't a theme namespace). Added an explicit `@utility z-overlay` in `styles.css`.
- **3D section trapped vertical scrolling on phones** (`touch-none`, while rotation is disabled on touch anyway). Now `touch-pan-y`.
- **3D canvas was destroyed/re-created on every scroll in/out** (new WebGL context each time). It now mounts once and pauses rendering off-screen (`frameloop`).
- **Porcelain / Form study toggles did nothing under reduced-motion** — now disabled with an explanatory note.
- **Hero bottom bar ("Scroll to explore", "01 / 09") was pushed below the first viewport** — hero is now a flex column.
- **Footer anchor links hid headings under the fixed nav** — added `scroll-padding-top`.
- **Nav order didn't match page order** (Philosophy is first on the page). Reordered nav + footer.
- Copy: "airway of light" → "bone, soft tissue".

## Performance
- Hero parallax and custom cursor no longer run a permanent `requestAnimationFrame` loop; they stop when settled.
- Cursor stays hidden until the first pointer move (was flashing at screen centre).
- Film-grain animation is static on touch devices.
- `loading="lazy"` / `decoding="async"` on all below-the-fold images (~5 MB of JPEGs).

## Accessibility
- Contrast: gold labels on ivory/bone were 2.3–2.6:1 → new `gold-deep` token (4.8–5.5:1); `stone` on dark backgrounds was 3.2–3.5:1 → `mist/70` (≈4.7–4.9:1); `stone` darkened slightly for light backgrounds.
- Before/after slider: visible drag handle, keyboard focus ring, `aria-valuetext`, vertical swipes still scroll the page.
- Hidden stacked images (Treatments, Experience) no longer exposed to screen readers; `aria-current="step"` on the process steps.
- Booking confirmation announced via `role="status"`.

## Refactor
- Duplicated smooth-scroll code (Hero, Navbar) → `src/lib/scroll.ts`.
- Removed a no-op `onMouseLeave` in Treatments.

## Not changed (your call)
- Booking form saves name/email/phone/note to `localStorage`, but nothing ever reads it back. Consider not persisting it.
- Images are 350–660 KB each; converting to WebP/AVIF would cut most of that.
- `.vercel/output` is a stale build — run `npm install && npm run build` to regenerate.
